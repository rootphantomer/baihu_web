# Security Policy

## Supported Versions

Only the latest release of the Baihu Animation website is supported with
security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please report security issues privately to
[baihu_animation@163.com](mailto:baihu_animation@163.com). Do not open a public
issue for a suspected vulnerability.

Please include the affected URL or component, reproduction steps, and any
supporting details. We aim to acknowledge reports within three business days.
